# تحويل المنصة إلى "مدرسة" بعدة مدرسين ومحتوى مجاني مفتوح

## الفكرة الجديدة

- المنصة اسمها "مدرسة" (بدون الميل لمدرس واحد)، وفيها أكثر من مدرس تضيفهم أنت من حسابك.
- ثلاثة صفوف فقط: الأول الثانوي، الثاني الثانوي، الثالث الثانوي.
- الطالب من الصفحة الرئيسية يختار صفه → يشوف مدرسي الصف ده → يفتح صفحة المدرس → يشوف كورساته → يفتح الدروس والفيديوهات والملفات والاختبارات **بدون تسجيل دخول ولا حساب**.
- كل المحتوى مجاني ومفتوح، ومفيش أكواد اشتراك.
- بيانات الطالب (اسمه، صفه، تقدّمه، نتائج اختباراته، ملاحظاته/مفضّلته) تُحفظ على جهازه فقط في المتصفح — قاعدة البيانات لا تسجّل أي شيء عن الطلاب.
- زر "تحميل النسخة الاحتياطية" ينزّل ملف بكل بيانات الطالب، وزر "استعادة نسخة" يرفع الملف ده على أي جهاز تاني.

## الصفحات بعد التغيير

صفحات عامة (بدون دخول):
- الرئيسية: تعريف بالمدرسة + اختيار الصف (٣ صفوف).
- صفحة الصف: قائمة مدرسي الصف (صورة + اسم + مادة + نبذة).
- صفحة المدرس: كورساته داخل الصف ده.
- صفحة الكورس: الوحدات والدروس، مشغّل الفيديو داخل المنصة، الملفات (رفع يدوي أو رابط)، الاختبارات.
- صفحة الاختبار: أسئلة حقيقية، النتيجة تُحسب وتُحفظ محليًا على الجهاز.
- صفحتي "ملفي": الاسم والصف، التقدّم، نتائجي، المفضّلة، وأزرار النسخة الاحتياطية/الاستعادة (كلها محلية).

لوحة الإدارة (حسابك فقط):
- المدرسون: إضافة/تعديل/حذف مدرس (اسم، صورة، مادة، نبذة، الصفوف اللي يدرّسها).
- الكورسات: لكل كورس مدرس + صف واحد محدد، وصورة غلاف.
- داخل الكورس: وحدات ودروس، فيديوهات (روابط)، ملفات (رفع أو رابط)، اختبارات (أسئلة وإجابات صحيحة).
- تبويبات/فلتر واضح بالصف: كل صف منفصل تمامًا عن التاني في العرض والإضافة، من غير أي تداخل.
- الملفات والصور بترفع فعليًا وتُحفظ وتُعرض صح (المشكلة الحالية في الرفع بتُصلَّح).

الصفحات اللي بتتحذف بالكامل: تسجيل/دخول الطلاب، صفحات الطلاب وبياناتهم، الإحصائيات الخاصة بالطلاب، المساعدين، الرسائل، أكواد الاشتراك، صفحات الملفات/الاختبارات المستقلة، الإشعارات والتعليقات والتفاعلات المرتبطة بحسابات الطلاب.

## البيانات

حذف كامل للبيانات والجداول القديمة (طلاب، أكواد، رسائل، تنبيهات، اشتراكات، تعليقات، تفاعلات، كورسات قديمة) والبدء بهيكل نظيف يحفظ فقط: المدرسين، الصفوف، الكورسات، الوحدات، الدروس، روابط الفيديو، الملفات، الاختبارات وأسئلتها، وصور المدرسين/الكورسات.

## تفاصيل تقنية

- قاعدة البيانات (ترحيل واحد): حذف الجداول القديمة، وإنشاء `teachers`, `courses`, `units`, `lessons`, `videos`, `lesson_files`, `exams` مع عمود `grade` مقيّد بالثلاث صفوف. قراءة عامة `TO anon, authenticated` (SELECT فقط للمنشور)، وكتابة محصورة على المدير عبر `has_role(auth.uid(),'admin')`/`is_teacher()` الحالي. GRANTs لكل جدول جديد. لا جداول أو صفوف لأي بيانات طالب.
- التخزين: باكتين عامّين للقراءة (`teacher-photos`, `course-covers`) + `lesson-files`، مع سياسات `storage.objects`: قراءة عامة، كتابة للمدير فقط. `src/lib/storage.ts` يرجّع رابط عام صحيح بدل `storage://` بحيث الصور تظهر بعد الرفع.
- الواجهة العامة: مسارات `src/routes/grades.$grade.tsx`, `teachers.$id.tsx`, `courses.$id.tsx`, `courses.$id.lessons.$lessonId.tsx`, `exams.$id.tsx` تقرأ عبر server functions عامة بمفتاح publishable (SSR آمن) + `head()` لكل صفحة.
- بيانات الطالب محليًا: `src/lib/local-profile.ts` بمخزن `localStorage` (اسم، صف، تقدّم، نتائج، ملاحظات/مفضّلة) + تصدير/استيراد ملف JSON بإصدار للتحقق، وصفحة `me.tsx`.
- الإدارة: تبسيط `dashboard/*` إلى `teachers`, `courses`, `courses/$id` مع مبدّل صف، وحذف مسارات الطلاب/الأكواد/الرسائل/المساعدين/الإحصاءات وكل الدوال غير المستخدمة في `platform.functions.ts`.
- إزالة تسجيل/دخول الطلاب: `signup.tsx` يتحذف، و`login.tsx` يبقى لحسابك فقط، والحماية تبقى على مسارات الإدارة.
